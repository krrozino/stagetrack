# Supabase migrations

Versione aqui todas as alterações reproduzíveis do banco do StageTrack.

Cada migration deverá incluir, quando aplicável:

- criação ou alteração de tabelas;
- foreign keys e constraints;
- índices;
- funções e triggers;
- habilitação de RLS;
- policies de acesso.

O modelo inicial de usuários será criado em uma migration própria durante a STG-005.
